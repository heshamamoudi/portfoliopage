# Portfolio Page

[![GitHub Pages deployment status](https://github.com/heshamamoudi/portfoliopage/actions/workflows/pages/pages-build-deployment/badge.svg?branch=feature/publish)](https://github.com/heshamamoudi/portfoliopage/actions/workflows/pages/pages-build-deployment)

A luxury-themed, fully responsive personal portfolio page for Hesham Amoudi.

## Description
This project is a modern, elegant portfolio page featuring:
- Light and dark luxury themes with a color palette inspired by gold foil, navy, and ivory silk.
- Sidebar navigation, animated profile, and interactive theme toggle.
- Responsive design for all devices.
- Contact form and professional experience sections.

## Build & Run Locally
1. Clone the repository:
   ```sh
   git clone https://github.com/heshamamoudi/portfoliopage.git
   cd portfoliopage
   ```
2. Serve locally (Python 3):
   ```sh
   python -m http.server 8080
   ```
   Then visit [http://localhost:8080/index.html](http://localhost:8080/index.html)
